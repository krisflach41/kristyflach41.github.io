Setup Guide

Facebook + Instagram (Meta): You need a Meta Business account with a connected Facebook Page and Instagram Business profile. Create a Meta Developer App at developers.facebook.com, add the Pages API and Instagram Graph API permissions, and generate a long-lived Page Access Token.

LinkedIn: Create an app at linkedin.com/developers with the "Share on LinkedIn" and "Sign In with LinkedIn" products. Generate an access token with w_member_social scope.

TikTok: Apply for TikTok for Business API access at developers.tiktok.com. Requires business verification — approval typically takes 1-2 weeks.

YouTube: Enable the YouTube Data API v3 in Google Cloud Console and create an API key. For posting, you'll also need OAuth 2.0 credentials.
